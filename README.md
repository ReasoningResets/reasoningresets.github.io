# Reasoning Resets

Project website for [Credit Assignment with Resets in Language Model Reasoning](https://arxiv.org/abs/2605.25507).

- General framework and theory: <https://reasoningresets.github.io/>
- Self-Reset Policy Optimization: <https://reasoningresets.github.io/srpo/>
- Public implementation: <https://github.com/Ankur-Samanta/SRPO>

The site is static HTML, CSS, and JavaScript deployed through GitHub Pages.
