02 / The theory

The useful learning signal lives in improvable states.

We study resets through Conservative Policy Iteration, the policy-improvement framework underlying methods such as PPO and GRPO. If exploration is expensive, the reset state—not merely the number of samples—determines how much useful signal reaches the update.

Step 1 · Find where improvement is possible

Most visited states may have little useful signal.

A state is τ-improvable when a different next action would be better by at least τ. If only one in ten visited states has that property, then pπ = 0.1. Those rare states dominate the opportunity for improvement.

Step 2 · Avoid signal dilution

Random sampling sees τpπ. Targeted sampling sees τ.

Random-reset CPI averages over every visited state. Because an improvable state appears only with probability pπ, its guaranteed advantage is diluted. A credit-assignment oracle conditions directly on the improvable set, preserving the full signal.

Step 3 · Convert signal into improvement

Targeting changes both estimation and the update.

A 1/pπ larger target cuts the rollout requirement by 1/pπ2. Restricting the update to the improvable set also permits a 1/pπ larger conservative step.

The realistic case

What if targeting is imperfect?

A practical localizer selects an approximate set 𝒮, rather than the true improvable set 𝒢.

If a fraction β of selected states are not improvable, the guaranteed signal falls from τ to (1−β)τ.

03 / From theory to practice

How can we do this in practice?

The theory asks us to target improvable states: states where the policy admits a strictly better action. Exact credit-assignment oracle access is an idealization. In practice, a localizer identifies improvable states only imperfectly, producing an approximate credit sampler. False discoveries dilute the signal, while missed improvable states shrink the mass on which the update applies.

One example

SRPO uses explicit self-localization.

In the RLVR setting, self-localization of the first erroneous step stands in for the credit-assignment oracle. Given a failed reasoning trajectory, the same policy that generated it is prompted to analyze its own trace. The reset state is the self-determined, verified-correct prefix preceding that error. The localization signal could instead come from a process reward model, step-level environment feedback, or a separate localizer.
